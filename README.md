# 2026 Programme Registration Portal

A complete Registration System for 2026 Programme. Users get instant Registration Number + PDF copy after submit. Includes Admin Dashboard with Export CSV.

📍 Haridwar, UK

### 🌐 Live
**Main Site:** https://registration-site-gi9s.onrender.com/
**Admin Dashboard:** https://registration-site-gi9s.onrender.com/admin

### ✨ Features
- 3-min registration flow
- Auto Reg No + PDF generation
- Each email can register only once
- Admin Panel - Search, Export CSV
- Mobile responsive

### 🛠️ Tech Stack
- Frontend: HTML, CSS, JS
- Backend: Node.js, Express
- DB: PostgreSQL / MongoDB
- Render Deployment
